# School Without Walls — Phase 0 Documentation Pack

A proposed implementation-ready baseline for a Nigerian-first multi-tenant school management and digital learning MVP.

## Start here

1. Read `docs/PRD.md` (scope, requirements, user journeys, permissions, curriculum, AI safety, acceptance).
2. Read `docs/ARCHITECTURE.md` (stack, tenancy, data boundary, hosting).
3. Open project root in Google Antigravity; its workspace rules are in `AGENTS.md` and `.agents/rules/security.md`.
4. Read `docs/IMPLEMENTATION_PLAN.md` and instruct agent to perform only `SWW-001`.
5. Review implementation tests/commit before authorizing next task.

**Current state:** This pack is planning/documentation only. It does not contain a running application or indicate that anything has been deployed.

**External concept reference:** https://github.com/hrshadhin/school-management-system — Laravel / AGPL-3.0. Do not directly copy implementation code without license review.
